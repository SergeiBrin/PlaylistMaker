# Playlist Maker

`Playlist Maker` — это Android-приложение для поиска треков, прослушивания превью и создания собственных плейлистов.

## Краткое описание проекта

Приложение позволяет:
- искать музыку через iTunes API;
- просматривать детали трека и запускать его превью в плеере;
- добавлять треки в «Избранное»;
- создавать, редактировать и просматривать плейлисты;
- хранить данные локально и работать с ними через удобный интерфейс.

В проекте используются классические Android-экраны (Fragment/ViewBinding) и современные UI-экраны на Jetpack Compose.

## Использованные библиотеки и технологии

- **Kotlin**
- **Android SDK / Jetpack**
- **Jetpack Compose** (UI)
- **Navigation Component** (Fragments + Compose Navigation)
- **ViewModel + LiveData**
- **Kotlin Coroutines**
- **Room** (локальная база данных)
- **Retrofit + Gson** (сетевые запросы и сериализация)
- **Koin** (dependency injection)
- **Coil** и **Glide** (загрузка изображений)
- **Material Components**
- **ViewPager2**
- **ConstraintLayout**
